## What it is
A hostel complaint and management website for students and wardens. It is a showcase: the server is simulated inside the page, so nothing is saved after a reload.

## Features
- 3D scroll landing page, light and dark theme, left-side menu
- Complaints with ticket numbers and a status (Submitted, Acknowledged, In Progress, Resolved, Closed)
- 11 categories, including Security and Rules & Conduct
- Private complaints (reporter name and room hidden from staff)
- 10 m location check (not applied to Safety / Urgent, Security, Rules & Conduct)
- Email OTP login (demo mode shows the code on screen)
- Community announcements
- Study Hub with free links to NPTEL, SWAYAM, NCERT and similar sources, with warden approval for student suggestions
- Warden dashboard with Conduct hotspots (patterns only, no names)
